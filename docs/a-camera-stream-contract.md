# A–C 시험 카메라 영상 연동 초안

2026-11-19 06:46 UTC: A 운영 서버에 배포하고 TLS 관리자 등록에서 `exam_camera_stream_v1:true`를 확인했다. A 카메라 변경은 통합 브랜치 `9fdc191`에 올라갔다. 로컬 TLS 테스트에서 선택 범위가 다른 관리자 차단, 카메라 off 뒤 미전송, DB 미저장을 확인했다. B의 실제 PC 영상 송신 및 C 화면 표시의 공동 검증은 남았다. C `c1bda54`는 기존 `subscribe_exam` 연결만 이용하므로 아래 영상 범위 구독과 아직 호환되지 않는다.

관리자별 서로 다른 토큰이나 PC별 권한 목록은 현재 없다. 기존 인증은 모든 PC를 관리할 권한을 가진 공통 관리자 토큰 한 종류다. 이 토큰으로 TLS 인증한 관리자만 선택한 PC·시험 한 건에 명시적으로 구독할 수 있다. 개별 관리자·PC 권한 분리가 요구되면 새 인증·권한 설계가 필요하며 공통 토큰을 개인별 권한 검증으로 해석하지 않는다.

별도의 관리자 TLS 연결을 만들고 첫 프레임으로 아래 등록을 보낸다. `pc_id`는 서버의 Agent 인증 설정에 등록된 ID여야 한다. 인증된 TLS 관리자 외에 Agent나 무인증 연결은 구독할 수 없다.

```json
{"type":"REGISTER","role":"admin","token":"기존 관리자 토큰","subscribe_camera":{"pc_id":"PC-02","exam_id":"exam-1"}}
```

성공 응답은 `REGISTER_RESULT`, `ok:true`, `exam_camera_stream_v1:true`다. 해당 연결은 선택한 PC의 해당 시험 영상만 받는다. PC 또는 시험을 바꾸면 이 연결을 닫고 새 범위로 다시 등록한다. 연결 생존을 위해 `LIST_DEVICES`를 주기적으로 보낼 수 있으며 응답과 `EXAM_CAMERA_FRAME`을 type으로 구분한다. 이 연결은 별도의 이벤트/상태 구독 및 명령 연결과 독립적이다.

Agent는 명시적 영상 공유 옵션과 서버 지원 플래그가 있을 때만 전송한다. 서버는 인증된 Agent의 PC ID, 시험 ID, 버전, 시간대 있는 시각, JPEG 형식, Base64, 24 KiB 이내 압축 데이터와 최대 320×240 크기를 검증한다. 서버가 확인한 해당 PC의 시험 모드가 켜져 있고 같은 시험 ID이며, 해당 시험의 카메라 상태가 `on`일 때만 같은 범위를 선택한 관리자에게 전송한다. Agent 재접속 시 기존 카메라 상태는 폐기한다. 화면을 열었으나 시험 상태가 미확인이면 C는 시험 상태 조회로 동기화해야 한다.

구독 연결당 대기 프레임은 최신 1개다. 3초 넘게 대기한 프레임은 폐기하며 영상을 DB나 로그에 저장하지 않는다. 중계 입력은 PC당 약 2프레임/초로 제한한다. 시험 종료·Agent 단절·카메라 off/오류에는 더 이상 프레임을 보내지 않는다. 전송 중인 프레임은 연결 종료/상태 변경과 경합할 수 있으므로 C는 상태 이벤트, 시험 종료·연결 단절 또는 3초 무수신 시 화면의 마지막 이미지를 지워야 한다. 유실된 프레임은 재전송하지 않는다.

모든 관리자가 동일 토큰으로 모든 PC에 접근할 수 있는 기존 정책이며, 영상 공유 옵션·시험 참여자의 카메라 권한 허용과 구분된다. 카메라 시험은 PC 소유자가 직접 참여한다. 실제 B Agent와 C GUI를 통한 검증 여부 및 운영 배포 상태는 별도 기록을 확인한다.
