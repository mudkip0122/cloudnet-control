# B 담당 로컬 검증 기록

검증일: 2026-10-30. 환경: Windows, Python 3.13, psutil 7.2.2. 아래는 EC2 준비 전 수행한 로컬 검증입니다.

| 항목 | 방법 | 결과 |
|---|---|---|
| PC ID 유지 | 임시 파일에 생성 후 다시 읽기, 별도 파일 및 수동 ID 비교 | 유지·분리 확인 |
| 잘못된 ID 파일 | JSON 오류·빈 ID 입력 | 원본 보존, 오류 처리 |
| 네트워크 속도 | 실제 경과 시간 기준 Mbps, 최초 샘플·카운터 감소·0초 검사 | 정상 계산·null 처리 |
| 수집 실패 복구 | CPU·RAM 오류를 주입한 후 다음 샘플 확인 | 실패 필드 null, 다음 샘플 복구 |
| 재접속 간격 | 연속 실패 단계 확인 | 3·6·12·24·30·30초 |
| 반복 서버 재시작 | 별도 로컬 포트의 실제 서버를 3회 종료·재시작 | 동일 Agent 프로세스·ID로 매회 새 실제 값 수신 |
| 중복 ID | 이미 연결된 ID로 두 번째 실제 Agent 실행 | 종료 코드 2, 재시도 반복 없음 |
| PC 세 개 분리 | 소켓 연결 3개 및 각각 다른 샘플값 사용, 한 연결 종료 | 해당 PC만 오프라인, 나머지 ID·값 유지 |
| 실제 GUI 연동 | 실제 수집 Agent → 서버 → GUI 수신 작업 및 위젯 값 검사 | 실제 숫자 반영, Agent 종료 후 오프라인 |

`unittest` 총 14개 통과. `tests.smoke_reconnect` 및 `tests.smoke_live` 통과.

실제 PC 3대·EC2·인터넷 단절·TLS·인증·30분 연속 안정성·종료/재부팅은 이 검증에 포함하지 않았습니다. PC 세 개 분리 검증은 같은 PC에서 소켓 기반으로 수행했습니다. A의 TLS·인증 규격과 EC2 준비 후 외부 연결 검증을 진행합니다.
