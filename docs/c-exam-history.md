# C 시험 모드 이력 정렬·지우기

- 시험 모드 창은 전체 PC의 최근 500개 이력을 **최신 수신순으로 위에** 표시합니다. PC별 시계 차이가 있으므로 서로 다른 PC의 원문 시각을 비교해 재정렬하지 않습니다. 각 행에는 원래 이벤트 시각을 그대로 표시합니다.
- 행을 선택한 뒤 ‘선택 내역 지우기’로 해당 event_id만 지웁니다. 새 이력이 추가돼 행 위치가 바뀌어도 선택한 이벤트를 유지합니다.
- ‘전체 내역 지우기’는 현재 표시된 전체 PC 내역을 확인 후 지웁니다. 확인 중 도착한 새 이력은 지우지 않습니다. 취소하면 변경하지 않습니다.
- 삭제 범위는 **현재 GUI 세션의 표시 이력**입니다. A의 SQLite 저장·감사 기록, 다른 관리자 화면, 현재 시험 모드와 감시 상태는 변경하지 않습니다. 서버 삭제 메시지나 DB 직접 접근을 추가하지 않았습니다.
- 지운 이벤트의 중복 억제 ID는 기존 최근 4096개 캐시에 유지하므로 같은 이벤트 재수신으로 되살아나지 않습니다. 새 event_id의 재감지는 정상적으로 추가됩니다. 일반 앱 복원에 따른 같은 PID의 새 이벤트도 포함합니다.
- 삭제 후 상단 금지 앱·Chrome 전환 경고는 남은 이력을 기준으로 갱신하고, 해당 종류의 이력이 없으면 표시할 이력이 없다고 안내합니다. 감시 정상이나 시험 준수를 뜻하지 않습니다.

검증: 실제 Tk에서 최신순 표시, 새 이벤트 도착 중 선택 유지, 선택 삭제, 전체 삭제 취소/확인, 확인 중 도착한 이벤트 보존, 경고 배너 갱신을 확인합니다. 모델 검증에서 삭제 후에도 현재 모드와 중복 억제가 유지되는지 확인합니다. 운영 시험 제어·프로세스 종료·서버 기록 삭제는 수행하지 않습니다.
