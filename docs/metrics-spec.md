# PC 식별 및 측정 데이터 공통 규격

1주차 A·B·C가 함께 사용할 데이터 기준입니다. 메시지 프레이밍·인증·등록 응답은 별도 프로토콜에서 정의합니다.

## 필드와 단위

| 필드 | 형식 | 의미·예시 |
|---|---|---|
| `pc_id` | 문자열 | 각 PC의 고유값. PC마다 다르고 Agent 재시작·재접속 후에도 동일한 값 사용 |
| `pc_name` | 문자열 | 등록 시 전달하는 표시 이름. 예: `TEAM-B-PC`. 중복 가능하며 식별에는 사용하지 않음 |
| `timestamp` | 문자열 | 측정 시각, UTC ISO 8601. 예: `2026-10-30T03:00:00Z` |
| `cpu_percent` | 숫자 또는 null | 전체 CPU 사용률, 0~100 %. 예: `23.5` |
| `ram_percent` | 숫자 또는 null | 전체 물리 메모리 사용률, 0~100 %. 예: `61.2` |
| `upload_mbps` | 숫자 또는 null | 해당 PC 기준 송신 속도, 0 이상 Mbps. 예: `1.25` |
| `download_mbps` | 숫자 또는 null | 해당 PC 기준 수신 속도, 0 이상 Mbps. 예: `12.8` |

PC ID의 실제 값은 각 PC에서 정하며, 개인별 고정값 하나를 여러 PC에 공유하지 않습니다. PC ID는 인증정보를 대신하지 않습니다. PC 이름은 등록 정보로 보내고 측정 메시지에는 PC ID를 포함합니다.

## 수집·표시 기준

- 수집·전송 주기는 기본 **2초**로 통일합니다.
- CPU는 전체 논리 코어를 합친 0~100% 기준이며 코어별 사용률의 합을 보내지 않습니다. `psutil.cpu_percent(interval=None)`의 첫 호출은 준비용으로 버리고 다음 측정부터 사용합니다.
- RAM은 `psutil.virtual_memory().percent` 값을 사용합니다.
- 네트워크는 `psutil.net_io_counters()`의 시스템 전체 송수신 누적 바이트 차분을 사용합니다. 인터넷 회선 속도 측정값이 아니라 해당 PC의 네트워크 트래픽입니다.
- 속도 계산: `Mbps = (현재 누적 바이트 - 이전 누적 바이트) × 8 / 실제 경과 초 / 1,000,000`. 시간 차이는 단조 시계로 계산합니다.
- 첫 네트워크 샘플, 카운터 감소·초기화, 경과 시간 0 이하, 수집 실패는 해당 필드를 `null`로 보냅니다. 카운터 초기화 후에는 새 기준값으로 다음 차분을 계산합니다.
- `0`은 정상 측정 결과 활동이 없다는 뜻이고, `null`은 측정값이 없다는 뜻입니다. GUI는 `null`을 `—`로 표시하고 그래프에서 누락 구간으로 처리합니다.
- JSON에는 단위 기호를 붙이지 않은 숫자를 보냅니다. GUI는 CPU·RAM 소수 1자리, 네트워크 소수 2자리로 표시합니다. 전송값은 표시를 위해 미리 반올림할 필요가 없습니다.
- Mbps는 초당 백만 비트입니다. MB/s와 구분하며 업로드·다운로드 방향은 항상 Agent PC 기준입니다.

## METRICS 예시

아래 PC ID와 수치는 예시이며 실제 측정 결과가 아닙니다.

```json
{
  "type": "METRICS",
  "pc_id": "example-pc-b-001",
  "timestamp": "2026-10-30T03:00:00Z",
  "cpu_percent": 23.5,
  "ram_percent": 61.2,
  "upload_mbps": 1.25,
  "download_mbps": 12.8
}
```

네트워크 첫 측정에서는 `upload_mbps`와 `download_mbps`가 `null`입니다. 접속 상태는 이 측정값에서 추측하지 않고 서버의 연결·Heartbeat 판정으로 별도 전달합니다.

## 담당별 사용

- **A:** 이 필드명·형식으로 메시지를 검증·중계하고, PC ID와 인증된 세션의 일치 여부를 확인합니다.
- **B:** 이 기준으로 수집하고 정상·결측 샘플을 제공합니다.
- **C:** 위 JSON으로 샘플 화면을 만들고, 같은 필드로 실제 서버 데이터를 표시합니다.
