## AWS 로그인 상태와 현재 운영 상태

기존 CLI 프로필 CloudNet Control은 존재하지만 로그인 세션이 만료되어 프로젝트 플랜/EC2 관리 API 조회는 완료하지 못했습니다. AWS CLI 2.39.5를 확인했고, aws login 실행 여부를 사용자에게 별도 확인 요청했습니다. 응답 없이 인증을 시작하거나 키를 대체하지 않았습니다. 이 문제와 별개로 기존 SSH 키로 EC2 배포·운영 검증은 완료했습니다. AWS 관리 API가 필요해지면 동의 후 기존 이름의 프로필로 재로그인하고 다시 확인합니다.

서버 서비스는 공동 검증을 위해 실행 상태로 유지합니다. 테스트용 로컬 Agent는 종료했으므로 PC-01은 이후 수동 실행 전까지 오프라인일 수 있습니다. 이 기록은 PC가 항상 켜져 있음을 보장하지 않습니다.
